# ANN Learning Project – Classification & Regression

This project was developed while learning Deep Learning fundamentals using TensorFlow, Keras, and Scikit-Learn.

The repository contains two end-to-end Artificial Neural Network (ANN) implementations demonstrating the two major supervised learning problem types:

## 1. Customer Churn Classification

Predicts whether a bank customer is likely to leave (churn) based on customer demographics, account information, and banking behavior.

**Output:**

* Churn Probability
* Customer likely to churn (Yes/No)

---

## 2. Salary Prediction Regression

Predicts a customer's estimated salary using demographic and banking-related features.

**Output:**

* Predicted Salary Value
